# iRevolution-A-Data-driven-Exploration-of-Apple-s-iPhone-Impact-in-India-using-Tableau
Overview
This project demonstrates the creation of an interactive data visualization dashboard using Tableau and its integration into a Flask web application. The dashboard provides insights on product sales, pricing, ratings, and popularity. Users can filter, explore, and interact with the data through a simple web interface. Tableau dashboards are published to Tableau Public and embedded into an HTML page served by Flask.
Features
Interactive Tableau dashboards with filters
Product analysis (sales, price, ratings, popularity)
Embedded dashboard in a Flask web app
Responsive UI using HTML + CSS + Bootstrap
Localhost deployment via Python Flask

How to Run
Clone the repository.
Install Flask: pip install flask
Navigate to project folder: cd tableau_flask
Run the app: python app.py
Open browser at http://127.0.0.1:5000 to view the dashboard.
Conclusion
This project integrates data visualization and web development to create an interactive dashboard for analyzing product data. It reduces manual reporting, improves insights, and provides an easy-to-use web interface. Ideal for academic demonstration or small-scale analytics projects.
